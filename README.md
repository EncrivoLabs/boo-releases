# Boo releases

Downloads for [Boo](https://boo.encrivolabs.com), a download manager that lives in your Mac's menu bar.

This repo only holds release files. The source is private.

## Download

[Download the latest Boo.dmg](https://github.com/encrivolabs/boo-releases/releases/latest/download/Boo.dmg)

Boo needs macOS 14 Sonoma or later and runs on Apple Silicon and Intel Macs.

## Check your download

Each release lists a SHA-256 checksum in `Boo-<version>.dmg.sha256`. To check it:

```
shasum -a 256 -c Boo-<version>.dmg.sha256
```
